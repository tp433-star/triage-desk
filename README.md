# Triage Desk

An independent prototype by Tanisha John, built for Uncountable's Product Manager (New Grad) role.

It takes raw issue reports, writes each one up as an engineering ticket (steps to reproduce, expected vs actual, implementation plan, acceptance criteria), ranks the week with adjustable weights, and routes each ticket to a coding agent, a planning doc, or back to the reporter.

Live: https://tp433-star.github.io/triage-desk/

Not affiliated with Uncountable. All 22 issue reports are sample data written for this demo. No customer, ticket, or code detail is real.

Single file, no build step: open `index.html`.
