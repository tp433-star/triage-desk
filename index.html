Triage Desk

The PM job at Uncountable is 20+ tickets a week with implementation plans, plus the call on which customer issue goes next. This desk takes raw issue reports, writes each one up as a ticket an engineer or a coding agent can start from, ranks the week, and says who should pick each one up.

Not affiliated with Uncountable. Every report below is sample data I wrote to resemble what an R&D platform's support channel might see. No customer, ticket, or code detail here is real, and the implementation plans name layers only, since I have not seen the codebase.

    Why tickets

    Uncountable's engineering page says agents wrote 75% of pull requests in July 2026 and 91% of product changes merged with no human approval. When code is that cheap, the ticket is what limits quality. A vague ticket gets a fast, confident, wrong pull request.

    Source: engineering.uncountable.com/coding

    How the ranking works

    Each ticket gets a 1 to 5 for severity, users affected, and account size. The weighted average is divided by an effort penalty, so a small fix to a serious problem beats a large fix to the same problem. Move the sliders and the queue re-ranks. The weights are an opinion you can argue with, which is the point.

    How the routing works

    Missing what's needed to reproduce: back to the reporter with specific questions. Touches the audit trail, permissions, signatures, or the data model, or is more than a few days of work: planning doc first. Everything else is written tightly enough to hand straight to a coding agent.
